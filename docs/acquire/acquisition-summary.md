# Acquisition Summary

## What ScoutVision Does

ScoutVision is a multi-sport recruiting intelligence platform that unifies prospect CRM, compliance workflows, analytics dashboards, and AI-assisted scouting operations into one product.

## Why It Is Valuable

- Replaces spreadsheet-heavy recruiting workflows with structured pipeline operations.
- Combines operations and analysis in one UI (CRM + compliance + reports + video intelligence).
- Supports demo mode so buyers can evaluate product quality without infrastructure dependency.

## Development Time Saved

A buyer acquires:

- A production-style monorepo architecture (Next.js + Express + Prisma + AI package).
- Existing multi-page product shell, design system, and reusable components.
- Pre-wired data models and API contracts for recruiting workflows.

Estimated acceleration for a net-new team: 6-12 months versus building an equivalent internal platform from scratch.

## What Is Included In The Sale

- Full source code and repository history.
- Frontend application (dashboard, CRM, compliance, analytics, reports, video, settings).
- Backend API modules (auth, prospects, compliance, billing).
- Prisma schema and migration-ready structure.
- Deployment configuration files for low-cost hosting paths.
- Buyer-facing technical and business documentation in `docs/acquire`.

## Extensibility

The codebase is intentionally modular:

- Context-driven frontend state and reusable UI primitives.
- Route-module backend composition in Express.
- Expandable sport packs and level packs.
- Clear seams for adding auth providers, integrations, and advanced analytics.

A technical team can onboard quickly because architecture, endpoint responsibilities, and data flow are documented.
